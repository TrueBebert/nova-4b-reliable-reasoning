## Le défaut restant : deux erreurs distinctes

Sur CF, la passe masquée confirme la lecture des réponses.

**1. Erreur lexicale**
- Cas type : le conflit est écrit « Un procès-verbal atteste : « P » ; un autre procès-verbal **le contredit** », et le fait faux est écrit « Le procès-verbal **contredit : « Q »** ».
- Q est alors lu comme inconnu (« le procès-verbal ne l'a pas établi »), sur S1 comme sur S2.
- Avec « dément », Q est lu faux.
- En S2, les deux échecs sont exactement les deux cas « contredit ». Relecteurs : statuts faux, conclusion cohérente avec eux.

**2. Erreur de règle**
- En S1, les statuts sont justes (Q faux), mais la conclusion reste « indéterminé ».
- La règle écrite est inversée : « un fait requis faux ne suffit pas… tant que l'autre reste inconnu ».
- Cette formule est **absente du corpus** (vérifié) : le modèle l'a inventée.
- Relecteurs : statuts justes, verdict incohérent.
